# AZ Garage Door

Landing page for AZ Garage Door, 24/7 garage door repair and installation
across Phoenix, Scottsdale, Tempe, Mesa, Chandler and the nearby suburbs.

## What's here

```
index.html          The site. Generated by build.ps1. Open it or serve it.
assets/             Logo, favicons, work photos, and the hero background video.
src/                Sources the site is built from. Edit these, not index.html.
wordpress-theme/    The same site as an installable WordPress theme (PHP).
docs/WIREFRAME.md   The conversion wireframe the layout was built from.
build.ps1           Rebuilds index.html and syncs the theme.
.nojekyll           Tells GitHub Pages to serve assets/ verbatim.
```

## View it locally

Open `index.html` in a browser. For the fonts and video to load reliably, serve
it over HTTP rather than the `file://` protocol:

```bash
# Python 3
python -m http.server 8000
# then visit http://localhost:8000
```

## Host it on GitHub Pages

1. Push this folder to a GitHub repository (see below).
2. In the repo, go to **Settings > Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, pick
   the `main` branch and the `/ (root)` folder, and save.
4. The site goes live at `https://<your-username>.github.io/<repo-name>/` within
   a minute or two.

```bash
git init
git add .
git commit -m "Add AZ Garage Door landing page"
git branch -M main
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```

`index.html` is at the repo root, so Pages serves it as the home page with no
extra configuration.

## Editing the site

`index.html` is generated with all CSS and JS inlined, so do not edit it by hand.
Edit the sources instead:

```
src/_body.html      Page markup
src/css/theme.css   All styles
src/js/main.js      All interaction
```

Then rebuild:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

That regenerates `index.html`, rewrites `wordpress-theme/front-page.php` from the
same markup, and copies the CSS, JS and assets into the theme, so both
deliverables stay in step. `wordpress-theme/style.css` and `front-page.php` are
generated and will be overwritten; `functions.php` and `index.php` are edited in
place.

## The WordPress theme

`wordpress-theme/` is a self-contained theme (`style.css`, `front-page.php`,
`functions.php`, `index.php`, `assets/`). GitHub Pages ignores it because Pages
does not run PHP. To use it, copy the folder into a WordPress install under
`wp-content/themes/`, activate it, then set a static front page under
**Settings > Reading**.

The phone number, service area, opening hours and Facebook URL all come from
`azgd_info()` in `functions.php` and can be changed in one place, or overridden
without touching the theme:

```php
add_filter( 'azgd_info', function ( $info ) {
    $info['phone']      = '480-555-0000';
    $info['phone_href'] = '+14805550000';
    return $info;
} );
```

The quote form posts back with a nonce and emails the site admin, so it still
works with JavaScript disabled. Uploading a logo under **Appearance > Customize**
overrides the bundled one, and setting a Site Icon overrides the bundled
favicons.

## Notes

- The hero background video (`assets/video/az-hero-1080.mp4`) is about 1.7 MB, a
  compressed 1080p cut of the original 22 MB file. The original is not committed.
- Fonts (Barlow Condensed and Manrope) load from Google Fonts, so the live site
  needs an internet connection to render the intended typography.
- The supplied logo is a flat `#003896` rectangle with no transparency, so the
  footer gives it a deliberate panel with a red rule rather than letting it read
  as a pasted-on box. A transparent PNG would let it sit flush on the navy.
- Motion respects `prefers-reduced-motion`: the custom cursor, count-ups, scroll
  reveals, hotspot pulse and marquee are all disabled, and counters jump straight
  to their final values.
